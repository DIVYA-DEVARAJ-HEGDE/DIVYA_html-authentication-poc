# 🌾 FarmConnect Authentication System

A **responsive and visually appealing authentication system** built using **HTML, Bootstrap 5, and custom CSS**.
This project demonstrates a complete authentication flow with modern UI/UX design and interactive features.

---

## 🚀 Features

* 🔐 Login Page
* 📝 Registration Page
* 🔑 Forgot Password Page
* 🔄 Reset Password Page
* 📊 Dashboard Page

### ⭐ Bonus Features Implemented

* 🌙 Dark Mode Toggle
* 👁 Show/Hide Password
* 🔒 Password Strength Indicator
* ⏳ Loading Button Animation
* 🎨 Smooth Hover Effects & Animations

---

## 🛠️ Technologies Used

* HTML5
* Bootstrap 5
* CSS3 (Custom Styling)
* Google Fonts (Poppins)
* JavaScript (for interactivity)

---

## 🎨 UI/UX Enhancements

* Responsive design (Mobile, Tablet, Desktop)
* Bootstrap card-based layout
* Custom color scheme (Agritech 🌾 theme)
* Smooth transitions and hover effects
* Clean and structured layout
