# 🌾 FarmConnect Authentication System

A responsive authentication system built using **HTML, Bootstrap 5, and custom CSS**.

---

## 🚀 Features

* Login Page
* Registration Page
* Forgot Password Page
* Reset Password Page
* Dashboard

### ⭐ Bonus Features

* Dark Mode Toggle 🌙
* Show/Hide Password 👁
* Password Strength Indicator 🔒
* Loading Button ⏳
* Smooth Animations 🎨

---

## 🛠️ Technologies Used

* HTML5
* Bootstrap 5
* CSS3
* JavaScript

---

## 📁 Project Structure
